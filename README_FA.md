# Particle Interactions - پورت غیررسمی برای Minecraft 1.16.5

این پروژه یک بازسازی مستقل و سبک از بخشی از افکت‌های مود اصلی برای Fabric 1.16.5 است؛
فایل JAR نسخه جدید به این پروژه تبدیل نشده و سورس اصلی سازنده نیز در این بسته وجود ندارد.

## افکت‌های پیاده‌سازی‌شده در این نسخه اولیه
- ذرات هنگام شروع شکستن بلوک
- افکت هنگام تعامل موفق با بلوک‌های قابل‌قرار دادن
- ذرات آتش و دود هنگام استفاده از فایرچارج یا فندک
- افکت پاشش هنگام استفاده از سطل آب
- افکت شعله هنگام استفاده از سطل لاوا

## محدودیت‌ها
این نسخه تمام قابلیت‌های مود اصلی را بازسازی نمی‌کند. قابلیت‌های پیشرفته‌ای مانند
ذرات اختصاصی برگ‌ها، minecart، رعدوبرق، زنبورداری، کوره‌ها، ذرات سفارشی با فیزیک،
سیستم تنظیمات و پشتیبانی از resource pack هنوز پیاده‌سازی نشده‌اند.
این‌ها نیازمند پورت جداگانه و تست درون بازی هستند.

## ساخت
1. JDK 8 را نصب کن.
2. Gradle 7.x سازگار با Fabric Loom 0.10 را نصب کن (برای نمونه Gradle 7.3.3).
3. در پوشه پروژه اجرا کن:

   `gradle build`

4. خروجی در این مسیر ساخته می‌شود:

   `build/libs/particle-interactions-1.0.0-1.16.5.jar`

## نصب
Fabric Loader برای Minecraft 1.16.5 و Fabric API سازگار با همین نسخه لازم است.
فایل JAR خروجی را در پوشه `mods` قرار بده.

## نکته مهم
من در این محیط Gradle را اجرا و کامپایل نهایی را تأیید نکرده‌ام. بنابراین این بسته
«سورس آماده ساخت» است، نه JAR کامپایل‌شده و تست‌شده. اگر خطای Gradle یا کامپایل دیدی،
متن کامل خطا را بفرست تا اصلاحش کنیم.
